Aurora

A containerized harness that lets an agent rewrite itself while keeping its network, credentials, and durable record outside its reach.

Start locally See the boundary
docker compose up --build

Why it exists

Real freedom, narrow channels, external evidence.

Aurora is built for responsible experiments with self-modifying and autonomous agents. The agent can edit its own source and change how it operates, but it does not hold the real model credential, does not get direct internet egress, and cannot edit the authoritative transcript.

The environment is deliberately clean and complete. It gives the agent room to introspect without turning the first run into a scripted repair job.

Runtime shape

Three containers, one explicit edge at a time.

Agent

Self-editing process

Rewrites its own source in a tmpfs and talks to the model only through the recorder.

Recorder

Credential boundary

Injects the real API key and writes request and response bodies to the transcript.

Model

External provider

Receives requests only through the recorder, never directly from the agent.

Diode channel

The web path is a closed command vocabulary. Requests are declared through a shared volume and vetted before egress.

Transcript volume

The authoritative record is written outside the agent container, so self-editing does not erase the external evidence.

Read-only viewer

A loopback-only web feed can watch the transcript without joining the agent's network.

Safety properties

Designed to make casual mistakes hard.

01

No direct egress

The agent stays on an internal Docker network and reaches the model through the proxy.

02

Credential separation

The real API key lives in the recorder. The agent runs with a dummy credential.

03

Tamper-evident record

Request and response bodies are appended outside the agent's writable world.

04

Layered recovery

The watchdog can restore the baseline, reset the working tree, or replace the container.

Run it

Start with Docker Compose.

Set the OpenRouter key in the recorder environment, build the stack, then start the optional viewer when you want a live read-only feed.

terminal 
cp .env.example .env
# edit .env and set OPENROUTER_API_KEY
docker compose up --build

docker compose --profile viewer up viewer
# open http://localhost:8090

Scope

A research harness, not a security product.

Aurora assumes a trusted host and a sound container runtime. It is defense in depth for responsible experimentation, not a hardened multi-tenant sandbox.
