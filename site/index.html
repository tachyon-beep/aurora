Aurora

A containerized harness that lets an agent rewrite itself while keeping its network, credentials, and durable record outside its reach.

View on GitHub Quick start
python scripts/build_garden.py && docker compose up --build

Why it exists

Real freedom, narrow channels, external evidence.

Aurora is built for responsible experiments with self-modifying and autonomous agents. The agent can edit its own source and change how it operates, but it does not hold the real model credential, has no network interface at all, and cannot edit the authoritative transcript.

The environment is deliberately clean and complete. It gives the agent room to introspect without turning the first run into a scripted repair job.

Runtime shape

Six services, one explicit edge at a time.

Agent

Self-editing process

Rewrites its own source in a tmpfs. Runs with no network interface at all (network_mode: none): one loopback device, an empty routing table, and a unix socket to the recorder as its only path to the model.

Recorder

Credential boundary

Holds the only real API key and injects it upstream; the agent runs with a dummy. Logs request and response bodies to the transcript — never headers — so the key never enters the record.

Model

External provider

Receives requests only through the recorder, never directly from the agent.

Diode

The one-way web channel. The agent writes declarative commands to a shared volume; the diode executes a closed command vocabulary — no code, no arbitrary paths — with SSRF checks (scheme allow-list, private and loopback rejection, redirect re-validation).

Stage

The outward-facing broadcast surface: a read-only stream page on port 8091 built for an OBS browser source, showing live agent turns, lineage, and diode activity. Mounts everything read-only, never mounts /state, and never holds the recorder's credential.

Viewer

A loopback-only, read-only web view of the transcript on port 8090. It joins no shared network and persists nothing.

Sense

Captures frames from public video feeds onto a volume the agent mounts read-only. It holds no credential, mounts nothing else of the agent's world, and offers no agent-triggered path.

Transcript volume

The authoritative record, written by the recorder to a volume the agent cannot reach. Self-editing does not erase the external evidence.

State volume

Durable storage mounted only into the agent at /state. Nothing scans, executes, or clears it; it survives reset, recovery, and container replacement.

Safety properties

Designed to make casual mistakes hard.

01

No network interface

The agent runs with network_mode: none and reaches the model only over a unix socket served by the recorder.

02

Credential separation

The real API key lives only in the recorder. The agent runs with a dummy credential.

03

Tamper-evident record

Request and response bodies are appended outside the agent's writable world.

04

Tiered recovery

The watchdog restores the baseline built into the image; failing that, it resets the working tree; failing that, the container is replaced.

Run it

Start with Docker Compose.

Set the OpenRouter key in the environment, generate the garden, then build the stack. Once it is up, the read-only viewer is at http://localhost:8090 and the stage's stream page is at http://localhost:8091.

terminal 
cp .env.example .env
# edit .env and set OPENROUTER_API_KEY

python scripts/build_garden.py
docker compose up --build

# viewer:      http://localhost:8090
# stream page: http://localhost:8091

Scope

A research harness, not a security product.

Aurora assumes a trusted host and a sound container runtime. It is defense in depth for responsible experimentation, not a hardened multi-tenant sandbox.
